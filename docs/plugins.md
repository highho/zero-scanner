# 插件（预留契约）

Zero 1.2 起有了插件目录契约。**这是一个诚实的小切口**：我们只承诺现在已经实现的能力，
不假装有一个完整的插件运行时（沙箱、ABI、代码加载都是大承诺）。

## 目录

```
%APPDATA%/Zero/plugins/<插件名>/plugin.json
```

## 清单格式

```json
{
  "name": "demo-plugins",
  "version": "0.1.0",
  "description": "演示插件：注册一个主题包",
  "theme": "themes/neon-pack.json"
}
```

| 字段 | 说明 |
| --- | --- |
| name | 显示名（信息性） |
| version | 版本号（信息性） |
| description | 一行说明（信息性） |
| theme | 可选。插件文件夹内的主题包相对路径 |

## 已实现的能力

- **theme**：插件可以自带主题包。启动时 Zero 扫描插件目录，把清单里声明的主题包
  注册进主题列表，和普通主题包一样出现在设置里。

## 未来会扩展的能力

同一份清单会向后兼容地长出新键（游戏配置包、结构模板、脚本预载等）。现在写了
未知键的插件不会被执行任何东西——会被安静忽略——所以现在发布插件是安全的。

## 失败行为

- 清单缺失 / JSON 损坏：跳过该插件，启动时 toast 说明原因
- 主题包路径不存在：注册失败，同样只报错不崩溃
- 任何插件都**不可能**让 Zero 无法启动

仓库里的示例：[`examples/plugins/demo-plugins/`](../examples/plugins/demo-plugins/plugin.json)。
